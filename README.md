# Esep

Esep — веб-сервис для анализа банковских выписок. Первый релиз ориентирован на PDF-выписки Kaspi Bank: пользователь загрузит выписку, а система разберёт операции, сохранит их и предоставит аналитику.

## Цель проекта

Сделать удобный и расширяемый сервис, который помогает понимать структуру доходов и расходов по банковским выпискам. Архитектура закладывается с учётом будущей поддержки Halyk, Freedom, Jusan и других банков.

## Технологический стек

- Java 21
- Spring Boot 3
- Maven
- PostgreSQL
- Spring Data JPA и Hibernate
- Spring Validation
- Lombok
- Spring Security
- OpenAPI / Swagger UI
- Docker Compose

## Архитектура

Проект строится по слоям: HTTP-входящие запросы будут обрабатываться контроллерами, бизнес-правила — сервисами, а доступ к данным — репозиториями. Парсеры банковских выписок изолированы в отдельном модуле, чтобы новые банки можно было добавлять без изменения аналитического и прикладного слоёв.

## Структура проекта

```text
src/main/java/com/esep
├── analytics/     # Расчёт и представление аналитики
├── common/        # Общие компоненты и константы
├── config/        # Конфигурация приложения
├── controller/    # REST-контроллеры
├── dto/           # Объекты передачи данных
├── entity/        # JPA-сущности
├── exception/     # Исключения и их обработчики
├── mapper/        # Преобразование entity и DTO
├── parser/        # Парсеры банковских выписок
├── repository/    # Spring Data JPA-репозитории
├── security/      # Конфигурация безопасности
├── service/       # Бизнес-логика
└── util/          # Вспомогательные классы
```

На текущем этапе в проекте создан только инфраструктурный каркас: бизнес-логика, API и модель данных ещё не реализованы.

## Быстрый старт

1. Установите Java 21, Maven и Docker.
2. Запустите PostgreSQL:

   ```bash
   docker compose up -d
   ```

3. Соберите проект:

   ```bash
   mvn clean install
   ```

4. Запустите приложение:

   ```bash
   mvn spring-boot:run
   ```

По умолчанию приложение использует PostgreSQL на `localhost:5432` с базой, пользователем и паролем `esep`. Параметры можно переопределить переменными `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `SERVER_PORT`, а для Docker — `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_PORT`.

После появления API документация будет доступна по адресу `http://localhost:8080/swagger-ui.html`.
